# Подготовка полной и серверной версий, 14 ноября 2026

Полная версия опубликована в ветках `diploma` и `main`, компактная поставка —
в `server`. Настройки и веса текущего профиля `test2` сохранены. Это выпуск для
контролируемого полевого испытания с ручной сверкой, а не подтверждение точности
пассажиропотока на маршруте.

## Состав

В полной версии сохранены исходники, автотесты, обучающие инструменты,
замороженная ручная разметка, числовые отчёты и происхождение десяти экспортов.
Добавлены [сводка экспериментов](../../docs/RESULTS.md),
[карта дипломных материалов](../../docs/THESIS.md),
[правила обновления веток](../../docs/REPOSITORY.md) и актуальная документация запуска.
Исторические протоколы остаются отдельными от текущих результатов.

Серверная поставка формируется из Git-объектов определённого коммита. В неё входят
программа и предпросмотр, три активные модели, конфигурация камеры, схема и клиенты
БД, Docker/Compose, настройка приватной `.env`, проверка SHA-256 и лицензии.
Файлы обучения, отчёты, тестовые записи, предыдущие модели и возрастные веса
в дерево и первоначальную историю серверной ветки не включаются.

Исходный коммит серверной программы и хеши всех файлов записаны в `release.json`
этой ветки. Исходники runtime копируются без изменений; Docker CMD явно включает
`--profile test2`. Профиль остаётся специфичным для исследуемой камеры.

## Проверки

Фактические результаты зафиксированы в [verification.json](verification.json).
Полный локальный прогон: **168/168 без ошибок и пропусков**, Windows / Python 3.14.
Чистый clone: те же 168 тестов найдены, 153 прошли, 15 ожидаемо пропущены из-за
отсутствующих приватных видео/кешей и отдельно включаемой PostgreSQL; ошибок нет.

Серверная версия: **53 файла, три ONNX-модели, 20 884 931 байт** без самого манифеста.
Хеши и исходный коммит — в [копии server_manifest.json](server_manifest.json).
Манифест прошёл проверку на Windows; все три модели загружены и выполнены
на синтетических входах. Linux Docker-образ собран, зависимости согласованы,
реальный CPU-инференс и Compose проверены. Контейнер непривилегированного
пользователя обработал пять пустых кадров через штатный `main.py --profile test2`
с настоящей тестовой PostgreSQL: ноль событий, контрольная точка `next_frame=5`,
`completed=true`. Это проверка запуска, а не качества подсчёта пассажиров.

Основной набор запускается с отдельной одноразовой PostgreSQL и всеми флагами
приватных видеорегрессий. Тесты серверного сборщика дополнительно проверяют:
отбор файлов из коммита вместо рабочей папки, исключение даже случайно
зафиксированных приватных файлов, запрет перезаписи выходной папки, обнаружение
изменённого файла и отказ от пути за пределами поставки.

Предыдущая отдельная проверка PostgreSQL, SQLite, службы и источников:
18 тестов, ошибок нет. PostgreSQL создана отдельно от рабочей БД и удалена
после проверки. Этот инфраструктурный тест использует синтетические детекции
для сценариев перезапуска и не является испытанием качества ML.

Проверка репозитория сверяет десять моделей, суммы отчётов, сохранённые хеши
ручной разметки, локальные ссылки и отсутствие секретов. Для поставки отдельно
проверяются её манифест, загрузка и инференс трёх моделей на синтетическом кадре,
CLI и конфигурация Compose. Данные пассажиров для такой проверки не нужны.

## Очистка

Воспроизводимые Python-кеши исключены из публикации. Виртуальные окружения,
видеозаписи, исходные наборы, ручная разметка, приватные аналитические материалы
и рабочая конфигурация не удалялись. Они исключены из Git и Docker-контекста.
Запрещены случайные тренировочные `.pt`/`.pth`, базы, секреты, архивы и записи.
Новый CI серверной ветки проверяет именно компактную поставку.

## Границы готовности

Прежние пропуски и ошибки ID сохраняются. Часовое узнавание в независимом
непрерывном потоке не подтверждено; отбрасывание кадров ради гарантированно
низкой задержки не реализовано. Эксперимент с детьми не показал исключений и
выключен. Требуются измерение скорости на выбранном сервере, доступ к камере,
несколько смен с ручной сверкой, контроль свежести кадров и согласованные бэкапы.

Публикация исходников и прохождение тестов не означают выполнение этих полевых
проверок. Полный автоматический подсчёт дня с полной ручной сверкой не выполнен.
