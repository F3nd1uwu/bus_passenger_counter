# Публикация архивной версии, 16 ноября 2026

Полные ветки `diploma` и `main` содержат программу, документацию, тесты и
аналитические протоколы. Отдельная ветка `server` обновляется обычным коммитом
поверх предыдущей поставки, без слияния истории полной версии.

Серверная поставка собрана из `696400e`: 112 файлов, 111 хешей полезной нагрузки,
четыре ONNX-модели — люди v2, OSNet ReID, жилетка v4 и OCR часов. В комплекте
веб-кабинет и инструкция UPDATE.md. Рабочие `.env`, видео, карты времени,
датасеты, базы, локальные трассы и тренировочные/возрастные веса не публикуются.
[Манифест](server_manifest.json), [проверки](verification.json).

Из чистой копии без приватных материалов в Linux/Python 3.12 выполнены
205 тестов: 193 прошли, 12 проверок приватных видео/кешей пропущены, ошибок нет.
Использована отдельная PostgreSQL. Дополнительно прошли 22 адресные проверки
Windows и 25 проверок веб-кабинета; новых миграций web нет. Проверены
Docker-сборка, хеши серверных файлов, локальный расчёт моделей без сети и
Compose-конфигурация с веб-кабинетом.

Тесты настроек и обновления состояния больше не требуют локального test.mp4.
Синтетический тест часов использует lossless-видео: значения пикселей кодируют
номера кадров и не должны меняться из-за различий MJPG между платформами.
Эти исправления затрагивают тестовые данные, не производственный алгоритм.

Это выпуск для контролируемого теста. Известный общий лишний вход свежего
пайплайна ONNX/OpenVINO сохранён в аналитике; он не представлен как исправленный.
Часовое узнавание на независимой смене не подтверждено. INT8 отклонён,
OpenVINO опционален, стандартный запуск остаётся ONNX.

[Архив и часы камеры](../archive-2026-11-15/README.md),
[CPU и расхождение свежего прогона](../cpu-optimization-2026-11-16/README.md),

Эта публикация не обновляет арендованный сервер и не останавливает его текущие
контейнеры. Перед серверным тестом загрузите приватные карты часов, сохраните
прежние результаты и используйте новые тестовые BUS_ID/STATE_PATH по инструкции.
