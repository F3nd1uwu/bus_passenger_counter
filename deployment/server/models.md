# Рабочие модели

Профиль `test2` использует ровно три ONNX-файла:

- `candidates/person_test2_v2.onnx` — детекция людей, confidence 0,30.
- `person_reid.onnx` — OSNet x0.25, признаки внешности.
- `candidates/work_vest_v3.onnx` — распознавание конкретной жилетки по чёрно-белому изображению.

SHA-256 всех файлов входит в [release.json](../release.json), происхождение весов —
в соседние JSON. Значение `export_sha256` в `person_reid.json` относится
к историческому TorchScript; хеш поставляемого ONNX берите из `release.json`.
Предыдущие модели, обучающие `.pt`, проверочный TorchScript и экспериментальные
возрастные веса не поставляются. Фильтр детей должен оставаться выключенным.

Параметры рассчитаны на определённый ракурс двери. При другой камере нужно
проверять геометрию, качество сопровождения и жилетку. Автоматическая загрузка
недостающих моделей при рабочем запуске не предусмотрена.
