# Проверенные и экспериментальные веса

## Приблизительный фильтр детей — эксперимент

Включается отдельно через `--child-mode model`; профиль `test2` автоматически
его не включает. `child_filter_v1.json` связывает два проверяемых по SHA-256 файла:
`child_vision_v1.onnx` (TinyCLIP, два вида фрагмента человека) и `child_age_v1.onnx`
(MiVOLOv2, дополнительная оценка по телу без видимого лица). Текстовые признаки
встроены в JSON; tokenizer и доступ к сети для запуска не нужны.

Оценки моделей не подтверждают реальный возраст. Нужны три последовательных
подтверждения на разных фрагментах одного трека; неопределённый результат
сохраняет человека в подсчёте. На шести видеопроверках исключений `CHILD` не было.
Улучшение качества подсчёта детей пока не доказано.

Рядом сохранены лицензии `LICENSE.child_vision.txt` и `LICENSE.child_age.txt`.
Для MiVOLO зафиксирована историческая ревизия официального LICENSE, указанная
в манифесте; условия текущих версий модели могут отличаться. Источник конкретного
ONNX и источник лицензии указаны отдельно. Экспорт воспроизводится через
`python -m tools.prepare_child_model --cache .local/child_model_sources --output .local/child_export`;
только для экспорта дополнительно нужен `tokenizers==0.23.3`.
Весовые константы MiVOLO хранятся в FP16 с возвратом в FP32 перед вычислением.

## test2 — экспериментальный профиль конкретной камеры

Запуск: `python test_local.py --source data/test2.mp4 --profile test2 --show`.

- `person_test2_v2.onnx`: дообученный детектор людей, confidence 0,30.
- `work_vest_v3.onnx`: отдельный детектор самой жилетки на чёрно-белом
  фрагменте человека. Добавлены проверенные отрицательные примеры обычной
  куртки со светлой вставкой. Для исключения нужны два последовательных
  подтверждения с confidence не ниже 0,20; это оценка модели, а не вероятность.
- Прежний `work_vest_ensemble.json` (v1 + v2, порог 0,50) сохранён для
  воспроизведения старых результатов. `work_vest_spatial.json` дополнительно
  требует совпадения расположения жилетки у двух моделей; в текущем `test2`
  этот вариант не используется.
- Решение о проходе может задерживаться до 10 секунд, чтобы увидеть жилетку
  после поворота. При завершении трека готовое решение выдаётся раньше.
- Веса и SHA-256 перечислены в соседних JSON. Обучающие `.pt`, изображения
  пассажиров и исходные видео не публикуются.

Это профиль одной камеры и одной рабочей жилетки. Сходная одежда, перекрытия
и новые ракурсы требуют дополнительной проверки. Часовая идентичность не
становится надёжной только от замены детектора. Профиль не включён по умолчанию.

[Исходные результаты и пропуски](../../reports/test2-2026-11-13/REPORT.md).
Исходные параметры этого отчёта сохранены отдельно в `profile_snapshot.json`;
текущий профиль обновляет модель жилетки, границу салона и защиту от дрейфа ID.
Надёжное сохранение часового ID этими обновлениями не подтверждается.

## person_manual_v1 — исходный профиль

`person_manual_v1.onnx` — FP32-экспорт YOLO26n для данной камеры.
Он включён в Git вместе с метаданными `person_manual_v1.json`.
Обучающий `.pt`, исходный датасет и большие архивы остаются локально.

Проверяйте веса вместе с их настройками:

```bash
python test_local.py --source data/test.mp4 --model models/candidates/person_manual_v1.onnx --confidence 0.35 --association-similarity 0.70 --show
```

- Confidence детектора: **0,35**, подобран на val по F1 боксов при IoU 0,50.
- Кратковременное сопоставление треков: **0,70**.
- Порог часового ReID: **0,85**, отдельный от порога трекера.
- Вход: 640 px, FP32; проверены формы 480×640 и 640×640.
- OSNet не дообучалась. Фильтр персонала отключён.

Данные: 350 изображений, 341 бокс. Train/val/test: 187/82/81.
Обучение: 23 эпохи, лучшая 15-я, AdamW, lr=0,0003, batch=4, freeze=10, seed=42, CPU.
F1 боксов на test: **0,634 → 0,765**.

Независимый аудит полного конвейера: **47/53 прохода**, recall **88,68%**,
precision **100%**, F1 **94%**. Есть ошибки трекинга и сохранения личности.
Известные эпизоды настройки с 20 IN / 11 OUT не следует выдавать за независимую оценку.
