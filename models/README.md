# Модели и происхождение

Полная ветка содержит десять экспортов для запуска, сравнения и воспроизведения
экспериментов. Компактная серверная ветка содержит только три рабочие ONNX-модели.

## Рабочий профиль test2

- `candidates/person_test2_v2.onnx` — детектор людей, confidence 0,30.
- `person_reid.onnx` — OSNet x0.25, признаки внешности для сопровождения и часовой памяти.
- `candidates/work_vest_v3.onnx` — детектор конкретной жилетки в чёрно-белом изображении.

Настройки — [config/profiles/test2.json](../config/profiles/test2.json).
В метаданных кандидатов сохранены хеши и параметры. Это профиль определённого
ракурса двери, а не универсальная настройка для любого автобуса.

## Другие экспорты полной ветки

| Файл | Назначение |
| --- | --- |
| `yolo26n.onnx` | Базовый детектор людей, FP32 640 px; встроенный профиль `Settings()` |
| `candidates/person_manual_v1.onnx` | Дообученный детектор, профиль нового `.env.example` |
| `person_reid.onnx` | CPU-энкодер OSNet x0.25, 512 признаков |
| `person_reid.torchscript` | Проверочный экспорт того же OSNet, тест численной эквивалентности |

SHA-256 базовых CPU-экспортов: `cpu_models.json`. Происхождение исходных весов OSNet:
`person_reid.json`, закреплённая ревизия Hugging Face и SHA-256 скачиваемого файла.
SHA-256 кандидата, параметры обучения и метрики: `candidates/person_manual_v1.json`.
Проверка всех десяти файлов: `python -m tools.check_repository`.

Кроме перечисленных четырёх исторических экспортов, в полной ветке находятся
жилетки v1/v2 для воспроизведения предыдущих опытов и две экспериментальные
модели возрастного фильтра. Вместе с тремя рабочими моделями это десять файлов;
OSNet ONNX входит и в рабочий, и в исторический список, отдельной копии нет.
Возрастной фильтр по умолчанию выключен и в серверную поставку не включается.
[Описание кандидатов](candidates/README.md).

Базовый ONNX получен из Ultralytics YOLO26n; кандидат дообучен на локальной ручной
разметке. OSNet обучена на MSMT17 и не дообучалась на этой камере. Архитектура OSNet
включена в `tools/vendor` с MIT-лицензией. Сведения о сторонних лицензиях:
[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).

Большой набор старых `.pt`, экспериментальные INT8/pose/helmet-модели, архивы и
результаты обучения исключены из Git, но не удаляются из локальной рабочей папки.
Подготовка собственных экспортов описана в [DEVELOPMENT.md](../docs/DEVELOPMENT.md).
