# Локальные данные обучения

Изображения пассажиров, исходное видео, разметка и архивы датасета не публикуются
в Git. При наличии локального датасета используйте структуру:

```text
datasets/bus_people/
  annotations.json
  manifest.json
  data.yaml
  images/{train,val,test}/
  labels/{train,val,test}/
```

Формат YOLO, проверка разметки и обучение описаны в
[руководстве разработчика](../docs/DEVELOPMENT.md).

## Новые данные test2

Локальные наборы `bus_people_v2` и `work_vest_detection_v2` содержат размеченные кадры
и вырезки из пользовательских видео; они не входят в Git. В первом сохранено исходное
разбиение старых изображений и добавлены отдельные интервалы нового видео. Во втором
размечена видимая жилетка; вырезки без видимой жилетки не получают положительную метку
только потому, что на них водитель. Кадры с неоднозначной видимостью исключены.

`python -m tools.train_garment --dataset datasets/work_vest_detection_v2 --weights <local.pt>`
проверяет ручные отметки, хеши, соответствие YOLO-меток, чёрно-белый вход и отсутствие
одинаковых эпизодов/изображений в разных частях выборки. Данные test не участвуют в обучении.
Распределение и ограничения описаны в [отчёте](../reports/test2-2026-11-13/REPORT.md).

## Подготовка внешнего CountPeople

`tools.prepare_countpeople` собирает отдельный кандидат из просмотренного экспорта,
прежней локальной разметки и отдельно проверенных пустых кадров. Требуется JSON
решений для каждого исходного изображения с хешами изображения и метки; отсутствующая
метка не превращается в пустой кадр. Соседние эпизоды и похожие кадры группируются
до разделения. Фотометрические варианты создаются только в train, val/test сохраняются.
Исходники и существующая папка результата не перезаписываются.

Локально подготовлен `datasets/bus_people_countpeople_v1`; подробности и рецепт
обучения находятся в его README. Проверка без обучения:

```powershell
python -m tools.prepare_countpeople --output datasets/bus_people_countpeople_v1 --verify-only
```

Для обучения отдельного кандидата рецепт можно передать без ручного повторения
параметров. `test` остаётся вне обучения, пути к данным и начальным `.pt`-весам
должны существовать локально:

```powershell
python -m tools.train_detector --recipe datasets/bus_people_countpeople_v1/train_candidate.yaml --threads 3 --validate-only
python -m tools.train_detector --recipe datasets/bus_people_countpeople_v1/train_candidate.yaml --threads 3
```

Сохраняются параметры рецепта, хеш начальных весов и снимок всех изображений/меток.
Существующие запуски не перезаписываются; экспорт и включение ONNX выполняются отдельно
после проверки полного подсчёта на контрольных видео.

Результат попытки дообучения и причины сохранения прежнего детектора:
[отчёт CountPeople](../reports/countpeople-candidate-v1/README.md).
Для жилетки сформирован отдельный локальный `work_vest_detection_v3_clean`:
10 новых отрицательных вырезок P02 добавлены в train; весь соседний участок
этого эпизода исключён из garment test. Проверка обучения дополнительно запрещает
соседние кадры одного источника в разных частях, даже если названия эпизодов отличаются.
